# Pixel Mail Club V12.2 — Opiniones compactas (demo)

- Agrega una tarjeta compacta después de «¿Qué trae tu cartita?» y antes de acceso e inscripción.
- Al tocar «Ver opiniones y fotitos» se abre un diálogo accesible con dos reseñas ficticias **claramente identificadas como ejemplos**. Las ilustraciones son decorativas, no fotos de clientes.
- «Dejar mi opinión» está deshabilitado intencionalmente: **no existe todavía un backend de reseñas ni moderación**, y no se envían ni almacenan comentarios o fotos.
- Para producción: autenticación de suscriptores, envío autenticado de opiniones, consentimiento de publicación, moderación por administradora y almacenamiento seguro de fotos; evaluar costos/cuotas de almacenamiento antes de habilitar.
- La inscripción existente sigue en modo demo si no hay API configurada.

GitHub Pages: publicar `docs` desde `main` como antes.
